Stream Probe Data & FFprobe Bypass
m3u-editor can probe each channel and ship the codec / resolution / bitrate metadata in their get_live_streams response. When that data is present, this plugin feeds it directly into Emby so the first playback skips the FFprobe pass and starts much faster.

m3u-editor supplies this data when stream probing is enabled. When data is absent, Emby falls back to FFprobe automatically. No plugin configuration is required; the plugin reads stream_stats directly from m3u-editor.
